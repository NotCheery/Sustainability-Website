# Sustainability Website

# About
This is a website focused on education regarding Sustainability. 
It contains brief information about sustainability and some ways to help.

# Built With:
-**Coding**: Html, CSS, JavaScript
-**Tools**: VScode

# Features
- Added a Navigation Bar to help users navigate the website
- Added a textbox and a subscribe button to subscribe to newsletters.
- Survey Form Button opens up a new tab assessing user response and feedback.
